# 자차보조금 정산

출장 자차보조금을 계산하고 결재용 증빙 문서를 만드는 사내 도구입니다.
Cloudflare Workers 위에서 동작합니다.

## 정산 공식

```
자차보조금 = 주행거리(km) ÷ 10 km/L × 오피넷 전국평균유가 × 1.2
```

10원 절사. 통행료·주차료는 실비로 합산합니다.
기준값은 `public/config.js` 에서 바꿀 수 있습니다.

## 구성

```
wrangler.toml        배포 설정 (자산 경로 · 서비스 바인딩)
worker.js            API 중계 · 허용 경로 제한 · API 응답 보호 머리말
public/
  index.html         화면 전체 (HTML · CSS · JS 한 파일)
  capture.html       증빙 화면 옆에 뜨는 캡처 도우미 창
  calculation.js     십진 정산 계산 · 입력 검증
  _headers           정적 자산 응답의 CSP 등 보호 머리말
  config.js          정산 기준값
  qr.js              QR 생성 라이브러리 (MIT · 수정하지 마세요)
```

증빙 사진을 폰에서 PC 로 보내는 릴레이는 별도 저장소(`jhleokim/receipt`)의
워커가 맡고, 이 워커가 서비스 바인딩(`RECEIPT`)으로 호출합니다.

## API 키

키는 **저장소에 두지 않습니다.** Cloudflare 비밀값으로 관리합니다.

| 이름 | 용도 | 발급 |
|---|---|---|
| `KAKAO_REST_KEY` | 주소 → 좌표 변환 | 카카오 디벨로퍼스 (승인 불필요) |
| `OPINET_KEY` | 유가 조회 | 오피넷 (무료 · 즉시) |

카카오는 **카카오 디벨로퍼스**에서 앱을 만들고 REST API 키를 받습니다.
길찾기(거리 자동 채움)를 쓰려면 그 앱에 **카카오모빌리티 길찾기**가 켜져 있어야 합니다.
오피넷은 홈페이지에서 무료로 즉시 발급됩니다.

등록은 다음과 같이 합니다.

```bash
npx wrangler secret put KAKAO_REST_KEY
npx wrangler secret put OPINET_KEY
```

## 배포

GitHub 연동을 쓰는 경우, `main` 브랜치에 push 하면 자동으로 배포됩니다.

로컬에서 직접 배포하려면

```bash
npm ci
npm run deploy
```

Wrangler는 `package.json`과 `package-lock.json`에 고정합니다. `npm run verify`는
전체 JS·HTML 내부 스크립트 문법, 정산식, 문서 좌표, 저장·복구, 프록시 캐시를 검사합니다.
GitHub Actions에서 실행하며, `wrangler.toml`의 `[build]`에서도 실행하므로 검증 실패 시 배포가 중단됩니다.
문서 좌표 테스트는 브라우저 글꼴·인쇄·캡처의 실제 시각 검증을 대체하지 않습니다.

## 화면 버전

`public/index.html` 의 `VERSION` 값이 화면 오른쪽 위에 그대로 표시됩니다.
화면을 고칠 때 **함께 올려 주세요.** 사용자가 고친 내용이 반영됐는지 확인하는
유일한 표시이고, 캐시 문제를 가려낼 때도 이 값을 봅니다.

## 알아 두면 좋은 제약

- **유가 자동 조회는 최근 일주일까지만** 됩니다. 오피넷 API(`avgRecentPrice`)가
  그만큼만 주기 때문입니다. 그보다 오래된 출장일은 조회화면을 열어 직접 넣습니다.
- **거리 자동 채움은 카카오 길찾기**(우선 안내 경로) 값입니다. 증빙으로 캡처하는
  네이버 지도 화면의 숫자와 다를 수 있어 화면에 그 사실을 함께 안내합니다.
- **증빙 화면과 캡처 창은 팝업**으로 열립니다. 팝업이 막혀 있으면 첫 화면에서
  허용 방법을 안내합니다.
- **입력값은 이 브라우저에만 12시간 임시 보관**됩니다(사진 제외). 서버로는
  보내지 않으며 `비우기` 로 고정값과 사진까지 모두 지워집니다. 고정값도 마지막 저장 후
  12시간이 지나면 다음 로드 시 삭제합니다. 만료 시각이 없는 이전 고정값도 삭제합니다.
- **정산 기준은 새로고침할 때 최신 config.js를 적용**합니다. 화면에서 바꾼 연비·가산율·
  원단위 처리·실비 합계 포함 여부는 현재 화면에서만 적용하고 초안에서는 복원하지 않습니다.
- 자동 유가·모달 반영값·왕복 표시·출처는 함께 저장합니다. 증빙의 유가 기준일은 자동
  조회에 실제 사용한 날짜를 표시합니다.


## API 접근 범위

카카오 주소·키워드 검색, 카카오모빌리티 `v1/directions`, 오피넷 유가,
영수증 릴레이의 지정된 GET 경로만 허용합니다. 사용하지 않는 TMAP 프록시는 제거했습니다.
다른 웹사이트에서 보내는 브라우저 요청도 거부합니다.
**경로 제한과 Origin 검사는 사용자 인증이 아닙니다.** 허용된 경로는 직접 HTTP 요청으로
호출할 수 있으므로, 사내 계정만 사용하도록 제한하려면 Cloudflare Access 정책과
API 호출량 제한을 운영 계정에서 설정해야 합니다. 현재 코드 변경으로 Access가 설정되지는 않습니다.

오피넷은 유효한 가격이 있는 성공 응답만 캐시하고, 빈 값·잘못된 JSON·실패 응답은
`no-store`로 반환합니다. 새 캐시 키를 사용해 이전 빈 응답 캐시도 재사용하지 않습니다.

## v5.5 리뷰 반영

- 문서의 실제 레이아웃을 두 번 실행해 출처·공식·안내문을 포함한 높이를 산출합니다.
- 금액은 십진 입력의 정수 비율로 계산합니다. 가산율·실비·유한값과 금액 범위를 검증합니다.
- 입력 미리보기는 프레임당 한 번 갱신하고, PNG·인쇄 전에는 최신 값을 즉시 그립니다.
- 사진 드래그는 캔버스의 포인터 캡처를 사용해 전역 이벤트 리스너 누적을 막습니다.
- 사진 릴레이는 암호학적 난수 UUIDv4를 만들고 서버도 UUIDv4 형식만 허용합니다.
