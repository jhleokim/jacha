# v6.0 한글·출력 개선

## 원인과 변경

- UI의 Pretendard는 글꼴 이름만 지정돼 있었고 실제 파일을 불러오지 않았다. 기기별 대체 글꼴과 캔버스에 고정된 맑은 고딕이 혼재했다.
- [공식 Pretendard 1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard)를 원본 그대로 자체 제공한다. 전체 한글을 포함하는 가변 WOFF2 2,057,688바이트이며 SIL OFL을 동봉했다. 외부 폰트 CDN 없이 400·500·600·700 굵기를 사용한다. 배포 전 SHA-256 검사로 손상을 막는다.
- 화면: 입력 16px, 주요 버튼 14–15px, 항목 14px, 설명 13–14px. 작은 화면에서도 글자를 일괄 축소하지 않는다. 줄간격과 실제 굵기를 맞추고 임의의 합성 굵기를 사용하지 않는다.
- 출력: 본문 11pt, 제목 22pt, 항목 제목 12pt, 출처 9pt. 큰 색 띠와 붉은 합계 대신 문서의 제목·항목·금액 위계와 정렬로 구분한다. 글씨 크기 조절 80–130%를 유지한다.
- PDF는 HTML 텍스트와 표로 인쇄한다. 서식 글자는 선택·검색할 수 있고 긴 내용은 다음 쪽으로 흐른다. 증빙 사진 안의 글자는 원래 이미지로 유지한다. 사진의 자르기·강조·크기 설정도 반영한다.
- PNG는 같은 글꼴과 데이터 모델을 사용하며, 한글의 실제 폭을 측정해 긴 주소와 출장목적을 줄바꿈한다. PDF와 PNG의 페이지 수·줄바꿈은 매체에 따라 다를 수 있다.
- 인쇄는 글꼴과 모든 증빙 이미지 준비를 기다린다. 실패·15초 초과 시 빈 문서를 출력하지 않고 재시도 버튼을 제공한다. PNG도 글꼴 준비 후 저장한다.

## 검증

- `npm run verify`: 61개 검사 통과. 계산 조합 45,000개를 포함한다.
- 주소 확인 전 숨김, 모든 후보 확정 후 공개, 입력 수정·다시 고르기·초기화 시 재숨김, 검색 실패 우회와 오래된 응답 무시.
- 출력 모델의 금액·출처·사용자 텍스트 이스케이프, 선택한 사진과 강조 좌표, 긴 한글 및 130% 글씨의 PNG 하단 잘림 여부.
- 글꼴/이미지 준비 전 인쇄 금지, 이미지 실패·시간 초과 후 재시도, 글꼴 누락 시 잘못된 대체 글꼴로 인쇄하지 않음.
- 실제 Chrome에서 자체 글꼴 로드, 데스크톱·390px 모바일 미리보기와 금액 행 정렬 확인. 인쇄 창 실행 확인. 브라우저 자동화로 OS 인쇄 대화상자의 최종 PDF 저장·추출까지 검증하지는 못했다.
