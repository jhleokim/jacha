# 자차보조금 정산

출장 자차보조금을 계산하고 결재용 증빙 문서를 만드는 사내 도구입니다.
Cloudflare Workers 위에서 동작합니다.

## 정산 공식

```
자차보조금 = 주행거리(km) ÷ 10 km/L × 오피넷 전국평균유가 × 1.2
```

10원 절사. 통행료·주차료는 실비로 합산합니다.
기준값은 `public/config.js` 에서 바꿀 수 있습니다.

## 구성

```
wrangler.toml        배포 설정 (자산 경로 · 서비스 바인딩)
worker.js            API 중계 (카카오 · 오피넷 · 영수증 릴레이) + 보호 머리말
public/
  index.html         화면 전체 (HTML · CSS · JS 한 파일)
  capture.html       증빙 화면 옆에 뜨는 캡처 도우미 창
  config.js          정산 기준값
  qr.js              QR 생성 라이브러리 (MIT · 수정하지 마세요)
```

증빙 사진을 폰에서 PC 로 보내는 릴레이는 별도 저장소(`jhleokim/receipt`)의
워커가 맡고, 이 워커가 서비스 바인딩(`RECEIPT`)으로 호출합니다.

## API 키

키는 **저장소에 두지 않습니다.** Cloudflare 비밀값으로 관리합니다.

| 이름 | 용도 | 발급 |
|---|---|---|
| `KAKAO_REST_KEY` | 주소 → 좌표 변환 | 카카오 디벨로퍼스 (승인 불필요) |
| `OPINET_KEY` | 유가 조회 | 오피넷 (무료 · 즉시) |

카카오는 **카카오 디벨로퍼스**에서 앱을 만들고 REST API 키를 받습니다.
길찾기(거리 자동 채움)를 쓰려면 그 앱에 **카카오모빌리티 길찾기**가 켜져 있어야 합니다.
오피넷은 홈페이지에서 무료로 즉시 발급됩니다.

등록은 다음과 같이 합니다.

```bash
npx wrangler secret put KAKAO_REST_KEY
npx wrangler secret put OPINET_KEY
```

## 배포

GitHub 연동을 쓰는 경우, `main` 브랜치에 push 하면 자동으로 배포됩니다.

로컬에서 직접 배포하려면

```bash
npx wrangler deploy
```

## 화면 버전

`public/index.html` 의 `VERSION` 값이 화면 오른쪽 위에 그대로 표시됩니다.
화면을 고칠 때 **함께 올려 주세요.** 사용자가 고친 내용이 반영됐는지 확인하는
유일한 표시이고, 캐시 문제를 가려낼 때도 이 값을 봅니다.

## 알아 두면 좋은 제약

- **유가 자동 조회는 최근 일주일까지만** 됩니다. 오피넷 API(`avgRecentPrice`)가
  그만큼만 주기 때문입니다. 그보다 오래된 출장일은 조회화면을 열어 직접 넣습니다.
- **거리 자동 채움은 카카오 길찾기**(우선 안내 경로) 값입니다. 증빙으로 캡처하는
  네이버 지도 화면의 숫자와 다를 수 있어 화면에 그 사실을 함께 안내합니다.
- **증빙 화면과 캡처 창은 팝업**으로 열립니다. 팝업이 막혀 있으면 첫 화면에서
  허용 방법을 안내합니다.
- **입력값은 이 브라우저에만 12시간 임시 보관**됩니다(사진 제외). 서버로는
  보내지 않으며 `비우기` 로 지워집니다.
