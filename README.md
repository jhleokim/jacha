# 자차보조금 정산

출장 자차보조금을 계산하고 결재용 증빙 문서를 만드는 사내 도구입니다.
Cloudflare Workers 위에서 동작합니다.

## 정산 공식

```
자차보조금 = 주행거리(km) ÷ 10 km/L × 오피넷 전국평균유가 × 1.2
```

10원 절사. 통행료·주차료는 실비로 합산합니다.
기준값은 `public/config.js` 에서 바꿀 수 있습니다.

## 구성

```
wrangler.toml        배포 설정
worker.js            API 중계 (카카오 · 오피넷)
public/
  index.html         화면 전체
  config.js          정산 기준값
```

## API 키

키는 **저장소에 두지 않습니다.** Cloudflare 비밀값으로 관리합니다.

| 이름 | 용도 | 발급 |
|---|---|---|
| `KAKAO_REST_KEY` | 주소 → 좌표 변환 | 카카오 디벨로퍼스 (승인 불필요) |
| `OPINET_KEY` | 유가 조회 | 오피넷 (무료 · 즉시) |

자세한 발급 절차는 `카카오키_받기.md` 참고.

## 배포

GitHub 연동을 쓰는 경우, `main` 브랜치에 push 하면 자동으로 배포됩니다.

로컬에서 직접 배포하려면

```bash
npx wrangler deploy
```
